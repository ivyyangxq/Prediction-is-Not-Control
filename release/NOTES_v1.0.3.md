# GQ Tool 1.0.3

Initial GitHub-ready Python distribution. MIT licensed, English-only workbench, notebook and documentation. The release assets are a wheel and a standard source distribution.

Install the downloaded wheel with pip, then launch `gq-tool`. See docs/START_HERE.md. The project is not yet published to PyPI.

Validation includes an installed one-seed controlled CM workflow, fixed reward, 24 periods, actual source recomputation, explicit repair, checkpoints and two-period ABCD. This does not establish statistical power or economic recovery. See docs/ONE_SEED_TEST.md for conditions and limits.

The project uses MIT, as selected by its owner. GitHub upload and remote CI must be verified independently; local release readiness is not a claim that publication is complete.
